# mongodb_atlas

MongoDB Atlas credentials and privileges. Dynamic credentials — provisions ephemeral DB users via the Atlas Admin API.

## Credential

```yaml
config:
  group_id: <atlas-project-id>
  db_name: <database-name>
  host: <cluster-hostname>
  # exactly one auth pair:
  client_id: <atlas-oauth-client-id>     # OAuth pair
  public_key: <atlas-public-key>         # API Key pair
secretRef:
  name: <k8s-secret>
  # canonical keys depend on auth pair:
  #   OAuth → client_secret
  #   API Key → private_key
```

`secretRef` keys: `client_secret` and/or `private_key` (whichever pair is in use).

### Auth method choice

- **OAuth** — requires `client_id` (config) + `client_secret` (secret).
- **API Key** — requires `public_key` (config) + `private_key` (secret).

Provide exactly one pair. Mixing the two is rejected.

## Privilege

```yaml
config:
  grants:
    - privileges: [FIND, INSERT]      # uppercase snake-case; or ["all"] (lowercase)
      resource_type: collection        # or "database"
      resource_names: [my_collection]  # forbidden when resource_type=database
```

Use `all` (lowercase) to grant every action allowed for the resource type.

Valid privileges for `resource_type: database`:

`ANALYZE_SHARD_KEY`, `BYPASS_DOCUMENT_VALIDATION`, `CHANGE_STREAM`, `CLEAR_JUMBO_FLAG`, `COLL_MOD`, `COLL_STATS`, `COMPACT`, `CONVERT_TO_CAPPED`, `CREATE_COLLECTION`, `CREATE_INDEX`, `DB_HASH`, `DB_STATS`, `DROP_COLLECTION`, `DROP_DATABASE`, `DROP_INDEX`, `ENABLE_PROFILER`, `FIND`, `INSERT`, `KILL_ANY_CURSOR`, `LIST_COLLECTIONS`, `LIST_INDEXES`, `MOVE_CHUNK`, `RE_INDEX`, `REFINE_COLLECTION_SHARD_KEY`, `REMOVE`, `RENAME_COLLECTION_SAME_DB`, `RESHARD_COLLECTION`, `SPLIT_CHUNK`, `UPDATE`, `VALIDATE`.

Valid privileges for `resource_type: collection`:

`ANALYZE_SHARD_KEY`, `BYPASS_DOCUMENT_VALIDATION`, `CHANGE_STREAM`, `CLEAR_JUMBO_FLAG`, `COLL_MOD`, `COLL_STATS`, `COMPACT`, `CONVERT_TO_CAPPED`, `CREATE_COLLECTION`, `CREATE_INDEX`, `DB_HASH`, `DROP_COLLECTION`, `DROP_INDEX`, `FIND`, `INSERT`, `KILL_ANY_CURSOR`, `LIST_INDEXES`, `MOVE_CHUNK`, `RE_INDEX`, `REFINE_COLLECTION_SHARD_KEY`, `REMOVE`, `RESHARD_COLLECTION`, `SPLIT_CHUNK`, `UPDATE`, `VALIDATE`.

## Required permissions on the auth principal

The Atlas key/OAuth principal must have organization-level permissions to manage database users in the target project — typically the **Organization Owner** role, or a custom role with database-user-management permissions.

## Connection-string template

```
mongodb+srv://${username}:${password}@${host}
```

Note: `${username}` and `${password}` are auto-generated by Hush — they're available in templates even though they're not user-supplied in the credential config.
